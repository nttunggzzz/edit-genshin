Ghép Hàng Loạt Từ File Excel / CSV

Quy định cột trong file Excel/CSV (theo đúng thứ tự):
  1. Cột 1: Mã acc (ví dụ 11171, CN#1076)
  2. Cột 2: Tài khoản HoYoLAB (Email hoặc Username)
  3. Cột 3: Mật khẩu HoYoLAB
  4. Cột 4 (tùy chọn): Nền (tên nhân vật hoặc ID nền, để trống là tự động)
  5. Cột 5 (tùy chọn): Màu khung viền (cyan, red, pink, purple, green, blue...)
* Hàng tiêu đề sẽ tự động được bỏ qua. Các tài khoản được xử lý tuần tự từng acc một. File gốc sẽ được xóa ngay sau khi nạp danh sách để bảo mật mật khẩu.
